# Native input trees implementation plan

> Approved owner design: implement declared trees first; audit diagnostics remain deferred. Execute this bounded meshes slice in the isolated native-input-trees worktree; engine import reuse is an independent agent-engine slice.

**Goal:** Declare a library once and invalidate native reuse when matching files are added, removed or edited.

**Architecture:** Extend `blender.inputs` with `{dir, include?, exclude?, maxFiles?, sha256?}` alongside existing explicit files. `captureBuildInputs` remains the owner of no-link file snapshots, pins and final input validation. Tree digests use sorted config-relative `{path, sha256}` records. Re-expand selected membership before publication; never discover imports or watch arbitrary project roots.

**Stack:** Node24 built-in `path.posix.matchesGlob`, existing TypeScript/Zod/Vitest. No new dependencies.
